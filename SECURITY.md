# Security

To report a security issue in this plugin (its skills and manifests) or in Fibery MCP, email support@fibery.io with "Security" in the subject: what you found, how to reproduce it, and the plugin version (`version` in `.claude-plugin/plugin.json`). Please don't post it in a public issue or on the community. We'll confirm we got it and follow up by email.

Only the latest version is supported: a fix ships as a new release, and installs pick it up when they update.
